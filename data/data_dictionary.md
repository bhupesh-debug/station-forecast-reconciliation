# Data Dictionary

All data is synthetic and generated by `src/data_pipeline.py` (seed 42 by default).

## `data/synthetic/station_monthly.csv`
| Field | Description |
|---|---|
| month | First day of month, 2017-01 to 2025-12 |
| station | Market id `ST01`..`ST17` |
| revenue | Monthly revenue, $M |
| opex | Monthly operating expense, $M (62-72% of revenue by station) |
| is_election_year | 1 in even calendar years |
| political_window | 1 in Sep-Nov of election years (political ad peak) |
| major_sports_event | 1 in months with a major live sports event (random, ~15% of months) |

## `data/synthetic/capex_projects.csv`
| Field | Description |
|---|---|
| project_id, station | Project and owning market |
| budget_musd | Approved budget, $M |
| planned_months | Planned duration |
| vendor_count | Number of vendors involved |
| scope_changes | Scope change requests logged |
| is_regulatory | 1 if the project is regulatory-driven |
| prior_overruns_at_station | Earlier overruns at the same station |
| overrun | Target: 1 if the project overran budget or timeline |
